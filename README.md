# ברכי · מחלקת הברכות של 42

**לייב:** https://orisamuel.github.io/brachi/

ברכי היא מנהלת מחלקת הברכות של 42 — אישה חרדית מודרנית ותקתקנית, עם ארבע דקות
בין בר מצווה לשבע ברכות. היא שואלת כמה שאלות על החוגג/ת (שם, מין, תפקיד, ותק,
מה הוא/היא אוהב/ת, תכונה, בדיחה פנימית), כמה רגש לשים (מ"ענייני" ועד "תביאו טישו")
ובאיזה אורך — ומוציאה ברכה + כרטיס מעוצב להורדה ולשיתוף.

זה גאג, לא מוצר: **אין פה בינה מלאכותית ואין שרת.** הברכה מורכבת בדפדפן ממאגר
ניסוחים בעברית (כולל הטיית זכר/נקבה ויחיד/רבים לפי השולח), והכרטיס נבנה בקנבס
מאיורים שנוצרו פעם אחת מראש. אין מפתחות, אין קריאות רשת מלבד הגופן.

## מבנה

| קובץ | מה יש בו |
|---|---|
| `js/greeting.js` | מאגר הניסוחים והמנוע. תחביר: `«זכר\|נקבה»`, `⟨אנחנו\|אני⟩`, `{name}` |
| `js/card.js` | הרכבת הכרטיס (1080×1350) בקנבס |
| `js/app.js` | הצ'אט עם ברכי |
| `img/cards/` | 10 איורים — שניים לכל רמת רגש |
| `img/brachi/` | ברכי בחמש תנוחות + אווטאר |

## הרצה מקומית

כל שרת סטטי. למשל:

```bash
npx http-server . -p 8742
```

---

*Brachi — a no-AI, no-server birthday-greeting gag for the 42 agency team. Vanilla JS
on GitHub Pages; greetings are assembled client-side from a Hebrew phrase bank,
cards are drawn on a canvas over pre-made illustrations.*
